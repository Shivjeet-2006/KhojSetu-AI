# KhojSetu AI

### Lost in words. Found through intelligence.

KhojSetu AI is a multilingual, voice-powered
lost-and-found matching platform for India.

## Key Features

- Voice-based lost and found reporting
- Indian language speech recognition
- Cross-language intelligent matching
- Explainable match suggestions
- Voice-based responses

## Technology Stack

- Python
- Gnani Prisma
- Gnani Timbre
- Multilingual NLP
- Streamlit
- SQLite
